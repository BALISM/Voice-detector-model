COMMAND SHEET (updated structure)
═══════════════════════════════════

Open PowerShell in the project root:
File Explorer -> open folder containing src, data, models, tests -> address bar -> type 'powershell' -> Enter. Confirm:
dir

You should see src, data, models, tests, docs, scripts.


CONVERTING & PREPARING TEST CLIPS (in tests\)
If you put non-WAV voice notes (.ogg, .mp3, .m4a) into tests\, convert them to .wav first:

powershell
Get-ChildItem tests\*.ogg | ForEach-Object {
    ffmpeg -i $_.FullName -ar 16000 -ac 1 "tests\$($_.BaseName).wav"
}


ADDING NEW POSITIVE SAMPLES
powershell
Get-ChildItem data\raw_voice_notes\pos_batchX\*.ogg | ForEach-Object {
    ffmpeg -i $_.FullName -ar 16000 -ac 1 "data\raw_voice_notes\pos_batchX\$($_.BaseName).wav"
}

Check current dataset files:
dir data\dataset\positive

Copy new files into positive dataset (Currently at wake_067.wav, so start $i at 68):
$i = 68
Get-ChildItem data\raw_voice_notes\pos_batchX\*.wav | ForEach-Object {
    Copy-Item $_.FullName -Destination ("data\dataset\positive\wake_{0:D3}.wav" -f $i)
    $i++
}

RETRAIN (run every time after adding data)
powershell
py src\extract_features.py
py src\train.py

Note: extract_features.py auto-generates augmented variants (pitch/speed/volume/noise shifted copies) of each sample, so total feature count will be higher than raw file count.


TEST A SINGLE FILE
powershell
# To test a file in tests\ folder:
py src\predict.py tests\new_test2.wav

# To test a sample in dataset:
py src\predict.py data\dataset\positive\wake_052.wav


TEST EVERY FILE IN tests\ AT ONCE
powershell
py src\test_all.py
